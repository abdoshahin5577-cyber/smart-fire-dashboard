# نظام الحماية الذكي للكشف المبكر عن الحرائق والاستجابة الفورية

واجهة تحكم ومراقبة حية (Dashboard) مبنية باستخدام **React.js** و **Tailwind CSS** لمتابعة قراءات مستشعرات الحريق والغاز والتحكم الفوري في أنظمة الطوارئ.

## المميزات الرئيسية
- **مراقبة حية للمناطق:** عرض لحظي لدرجات الحرارة، نسبة الدخان والغاز، وحالة اللهب.
- **نظام محاكاة للطوارئ:** زر اختبار لمحاكاة اندلاع حريق ومشاهدة استجابة النظام الآلية.
- **تحكم يدوي وفوري:** أزرار لتشغيل مضخات المياه، فتح مخارج الطوارئ، وفصل التيار الكهربائي.
- **دعم كامل للغة العربية (RTL):** تصميم متجاوب ومريح للعين.

## خطوات التشغيل محلياً
1. تثبيت المكتبات المطلوبة:
```bash
npm install
```
2. تشغيل خادم التطوير:
```bash
npm run dev
```
